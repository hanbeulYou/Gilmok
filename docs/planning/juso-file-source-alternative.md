# 대안 기록 — Juso 배포 파일 좌표

2026-10-21 사용자 결정으로 **조사 중단 / 미채택**. 현재 Juso API를 유지하고 도쿄 DB 저장을 선택했다. 근거·잔여 리스크는 [ADR](../decisions/20261021-juso-api-coordinates-tokyo.md)을 따른다.

- 실제 받은 건물DB `202609_건물DB_전체분.zip`은149,249,915B, 서울 `build_seoul.txt`는593,101행/93,995,042B/31열이다. 월변동 ZIP은595,469B, 서울 건물 변경은666행이다.
- 건물DB는 관리번호·법정동/지번·건물명/상세건물명을 제공하지만 XY는 없다. 위치정보요약DB 레이아웃은 주출입구 XY(GRS80 UTM-K)를 제공하지만 관리번호·지번은 없다. 관리번호→건물DB→도로명주소 복합 키→출입구 연결이 필요하다.
- G API13,460주소는 건물DB 관리번호100% 매칭, 대표 PNU 차이1주소, 복수 건물이 같은 주소 키를 쓰는 주소2,152개였다. 좌표 전체파일은 신청 대상으로 미확보했으므로 좌표 거리 중앙값/p95/최대와 서울 위치파일 행수·용량은 **미측정**이다.
- 공공데이터포털 첨부는 좌표 행이 아닌 레이아웃 PDF였다. 첨부의 공공누리1유형을 신청 대상 전체 좌표DB 이용조건으로 확대하지 않았다. 파일 방식이 해외 저장 문제를 자동 해결한다는 결론은 내리지 않는다.
- 양쪽 활용가이드 본문 버전 번호는 미표기이며 PDF 생성/수정 메타는2025-12-17이다. 건물DB의31/73 추가·34 수정·63/72 삭제와 위치정보요약DB의31/34/63 변동 적용 구조까지 확인했다. 배포 파이프라인·테이블·등록 경로는 구현/변경하지 않았다.
