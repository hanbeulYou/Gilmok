## 1. 목표·범위

선택 후보의 **채점에 사용한 중심 좌표·주반경** 안에 있는 개원 학원·교습소를 줌15 이상에서 표시한다. 분야별 색을 구분하고 선택 후보 프리셋과 같은 분야를 강조한다. 점을 누르면 **학원명·분야·주소에 명시된 층**만 보여준다. cluster 근거에서 지도를 열고, 점 선택 시 같은 후보의 cluster 근거와 연결한다.

현행 screens §4.3은 “입시·보습만”이다. 이번 사용자 요청인 **분야별 표시·동일 분야 강조**를 계획 범위로 우선하며, 승인 후 문서 커밋에서 해당 문구를 맞춘다. 그 밖의 채점식·가중치·분야 분류·후보 선택 계약은 유지한다.

- 주반경은 현재800m, 비교가1,000m 프리셋이면1,000m. 학교용1km나 역용1.2km를 학원 반경으로 사용하지 않는다.
- “같은 분야”는 후보 사업자가 입력한 과목이 아니라 `preset.cluster_field`다. 현재는 원문 키 **`입시.검정 및 보습`**. 국어·영어·수학을 새로 추론하거나 후보별 분야 선택 기능을 추가하지 않는다.
- 데스크톱·모바일 2D를 기본으로 지원한다. 이미 켠3D에서도 동일한 지도 점 선택이 가능하게 하되 새3D 코드나 deck.gl을 로드하지 않는다.
- 학원 리뷰·전화·운영자·대표자·수강료·개인과외·상세주소·호수·대장 용도·학원별 점수는 표시하지 않는다. 후보 등록/변경도 점 클릭으로 실행하지 않는다.
- 기존 카카오 좌표 삭제,13,542주소 전량 재산출, 원격 데이터 승격은 **계획 승인만으로 실행하지 않는다**. 아래 선행 작업의 manifest·영향 보고 후 별도 승인을 받는다.

## 3. 좌표 사용 가능 여부와 선행 조건

### 3.1 카카오 좌표를 신규 지도 레이어에 그대로 쓰지 않는 안 — 추천

2026-10-12에 [카카오 서비스 약관](https://developers.kakao.com/terms/ko/site-terms), [운영정책](https://developers.kakao.com/terms/ko/site-policies), 공식 Map 담당자의 [2025-07-22 저장·캐시 답변](https://devtalk.kakao.com/t/api/145284), [2026-02-02 POI DB 답변](https://devtalk.kakao.com/t/api/148194), [2026-09-04·09-07 일시 비교 답변](https://devtalk.kakao.com/t/local-api/151505)을 재확인했다. 담당자는 응답의 저장 이용을 허용하지 않고 실시간 사용을 안내하며, 일시 비교 후 폐기와 독립 공공데이터 저장을 구분한다. 기존 영속 좌표의 재배포·MapLibre 표시를 허용하는 근거는 확인하지 못했다. [A 착수 정책 확인](../validation/s3-2-a-kakao-policy-20260930.md)과 같은 판단이다.

이는 “좌표는 공공 주소에서 구했으니 자유 사용”이라는 가정으로 해결되지 않는다. 현재 NEIS 기관명·분야의 공공누리 이용조건과 **카카오가 반환한 좌표의 이용조건은 별개**다. 카카오 출처 문구를 붙이거나 provider 문자열만 `juso`로 바꾸는 방식도 전환이 아니다. 카카오를 제거하기로 한 기존 사용자 결정을 유지해 **공개 레이어 전에 독립 Juso 재산출을 완료**하는 안을 추천한다. 개발·회귀는 합성 데이터와 허용이 확인된 공공 좌표로 진행할 수 있다.

기존 저장 자료를 이번 계획에서 삭제하지 않는다. 보존/삭제 대상과 백업의 처리까지 A0 manifest에서 결정한다. 이 계획은 기존 저장·채점 경로 전체의 이용 적법성을 새로 승인하는 문서가 아니다.

### 3.2 Juso: 저장과 해외 처리 조건을 구분

[좌표 API 공식 카탈로그](https://www.data.go.kr/catalog/15056663/openapi.json)는 이용허락범위 제한 없음으로 표시하며 출입구 좌표 필드를 설명한다. [data-sources §2.8.3](data-sources.md#283-약관저장-허용출처--2026-09-30-확인)의 API 저장 가능 안내를 따르되, 이 라이선스만으로 해외 DB·R2·CI 저장까지 허용됐다고 단정하지 않는다.

A0는 **공개 좌표 API의 Tokyo DB/해외 백업 적용 범위 미확정**을 남겼다. 당시 근거인 [공식 해외 서버 Q&A114474](https://eng.juso.go.kr/addrlink/qna/qnaDetail.do?bulletinRefSn=114474&currentPage=184&keyword=&noticeMgtSn=114474&noticeType=QNA&noticeTypeTmp=QNA&page=&searchType=)는 이번 재조회에서 timeout이었다. 당시 확인 기록과 이번 조회 실패를 구분한다. 원문·공식 답변으로 공개 검색API(좌표), 저장국가, 백업, R2, Actions artifact 각각의 범위를 확인하고 전량 원격 저장 전 해소한다. 기존1건 호출 성공은 해외 저장 허용 증거가 아니다.

- `JUSO_API_KEY`·`JUSO_COORD_API_KEY`는 기존 발급/등록 경로를 재사용한다. 이번 계획을 위해 새 키나 Vercel 변수를 요구하지 않는다.
- 배치 좌표 경로는 Juso만. Vworld의 국내 IP 제약 때문에 Actions에서 폴백하지 않는 현행 D5 결정을 유지한다. 0건/불일치/제한/오류는 구분하고 카카오 좌표로 대신 채우지 않는다.
- 검색 결과의 주소·`bdMgtSn`·PNU를 검증하고, 원좌표 EPSG:5179→DB4326, 거리계산5186/geography를 사용한다. 공급자·원CRS·좌표·조회일·판정 근거를 남긴다.
- 출입구는 건물 중심/층 위치가 아니다. 같은 건물 여러 기관의 같은 좌표는 정상이다. 도형이 있는 지역에서는 같은 PNU의 `ST_Covers` 및 밖인 경우 거리를 검증하되, 도형 안으로 임의 이동하지 않는다. 강남구 외처럼 건물 도형이 없는 지역은 “도형 검증 불가”이며 이것만으로 Juso 주소 좌표를 폐기하거나 건물 중심을 추정하지 않는다. 주소/좌표의 실제 PNU 불일치는 검토 대기다.
- 기존 공식 쿼터 근거인 좌표5초10건에 맞춘600ms 간격과 retry/backoff·영속 journal을 재사용한다. 실제 승인키 조건은 재확인한다.13,542건이 모두 좌표 호출 대상이면 좌표 간격만 약2.26시간이며 검색·검증·재시도·기준분포 생성 시간은 별도다. 실행 시간 보장값이 아니다.

해외 저장 제한이 적용되면 A0의 서울 리전 이전 계획을 재검토한다. 리전 이동/클라우드 설정은 자동 실행하지 않고 사용자 승인을 받는다.

### 3.3 원천 교체와 채점 일치

지도만 Juso 좌표로 바꾸고 cluster는 카카오 좌표를 계속 쓰면 반경 경계의 기관 수가 달라진다. 따라서 **지도 좌표와 채점 `academies.geom`은 같은 승인 snapshot**을 써야 한다.

1. 기존 원천·좌표·기준분포 fingerprint와 rollback manifest를 고정한다. 최신 원천의 ID·이름·분야는 유지하고 승인된 주소 집합을 독립 재산출한다. 층 표시용 파생 자료도 같은 원본 해시에서 만든다.
2. 대조 보고: 신규 성공/실패, PNU 일치/불일치/도형 없음, 이동거리 구간, 기관별 반경 출입, a~e8축·총점·신뢰도·순위, 기존 무작위5셀. 현재 기대 순위와 달라지면 축별 원인을 보고한다. 점수를 맞추려고 좌표나 분류를 변경하지 않는다.
3. #37의 `ingest/refresh_monthly.py` 원천+score_reference **단일 원자적 승격**을 재사용/확장한다. 학원·학교 공유 캐시로 영향받는 원천, 지도 표시용 자료와 기준분포를 함께 검증해 교체한다. 지도 자료만 먼저 최신으로 게시하지 않는다. 기존 고정 cluster 스케일·v0.4.0 모델을 재조정하지 않는다.
4. 스테이징·실패 주입·재실행·rollback을 로컬에서 확인하고 원격 쓰기 범위/행수/SHA/시간을 보고한다. 사용자 manifest 승인 후 승격한다. 캐시·키 삭제는 별도 승인 범위를 따른다.
5. 이후 월간 갱신에서도 기관 원천·층 파생·좌표 provenance·지도 revision·기준분포가 같이 성공하거나 모두 이전 버전으로 남는지 시험한다. 새 학원/학교 주소가 생겨도 과거 카카오 캐시를 우선 선택하는 경로가 남지 않도록 `attach_cached_coordinates`를 점검한다.

## 4. 근거 숫자와 지도 집합 계약 — D3 추천안 확정

`score_internal.compete`의 현행 조건을 그대로 따른다: **개원**, `academies.geom`의 geography `ST_DWithin(center,radius_m)`, 원문 `field`별 `count(*)`. 학원/교습소 각각의 ID를1곳으로 센다. 같은 건물·이름·좌표로 합쳐 기관 수를 줄이지 않는다. [PostGIS 거리 함수](https://postgis.net/docs/ST_DWithin.html)의 단위와 경계 판정을 재사용하고 화면 pixel거리·지도 BBox로 점수 모집단을 정하지 않는다.

정상 응답의 불변식은 다음과 같다.

```text
ScoreResult.axes.cluster.evidence.values.n_field
 = score_inputs.compete.academies_by_field[preset.cluster_field] (해당 키 없음은0)
 = academy_layer.counts.radius_same_field
 = 지도 반경 집합에서 같은 field인 고유 기관 ID 수
 = 겹친 위치별 same_field_count 합
```

**“현재 화면에 보이는 점 수”를 문자 그대로 항상 위 값과 같게 만드는 것은 별도 UI 제약 없이는 불가능하다.** 사용자가 반경 밖으로 pan하거나 같은 좌표에 여러 기관이 겹칠 수 있다. 모바일에서는 줌15 이상과 반경800m 전체를 화면에 넣는 조건을 동시에 만족하지 못할 수도 있다. 이 충돌을 완료로 숨기지 않고 D3에서 계약을 확정한다.

추천은 **반경 전체 기관 수와 일치하는 지도 데이터 집합**을 보장하고, 근거에 `반경 내 같은 분야 N곳 · 현재 화면 안 M곳(겹친 점은 기관 수로 합산)`을 병기하는 방식이다. N은 점수의 원시값, M은 화면 안내이며 pan으로 N/점수를 바꾸지 않는다. 실제 화면 안 M은 보이는 지도 영역의 고유 기관 ID를 기준으로 계산하며 타일 복제 feature·겹침을 중복 집계하지 않는다. 줌15 미만은 “15 이상으로 확대하면 학원 표시”로 표시하며0곳으로 쓰지 않는다.

- 근거의 “지도에서 보기”는 해당 후보 선택을 유지하고 지도/모바일 지도 탭·학원 레이어·동일 분야 강조를 연다. 가능한 화면에서는 반경 전체 fit, 필요 시 줌15로 이동하고 화면 일부만 포함됨을 알린다. 자동 fit으로 사용자 탐색을 반복해서 덮어쓰지 않는다.
- 점 클릭은 후보 열을 다른 후보로 바꾸지 않고 동일 후보 cluster 근거를 연다. 근거의 N과 지도 N을 강조하고 선택 기관 팝업을 표시한다. 다른 분야 점은 “비교 분야 아님”을 분야 표시로 구분하며 N에 포함하지 않는다.
- 지도 source가 준비될 때까지 N값을 지도 검증 완료로 표시하지 않는다. NULL/로딩/실패와 정상0을 구분한다.
- 캐시 키에 실제 채점 중심·반경·분야·원천 revision을 포함한다. 후보/층 변경 시 이전 비동기 응답은 폐기한다. 같은 중심·반경·revision인 층 후보끼리는 공개 점 데이터를 공유하되 선택 상태는 후보별로 유지한다. 임대료/가중치 슬라이더는 조회를 다시 하지 않는다.
- `meta.sources`의 학원 version/적재 revision과 RPC의 원천 revision을 대조하고 N도 비교한다. 갱신 경합/저장된 오래된 비교는 “데이터 기준이 달라 재계산 필요”로 표시, 기존 점수는 보존하고 최신 지도를 동일 근거라고 연결하지 않는다. 같은 N이라도 revision이 다르면 통과시키지 않는다. 기존 메타가 revision을 유일하게 표현하지 못하면 새 메타 계약안을 먼저 보고한다.
- 좌표 NULL인 기관은 반경 소속을 알 수 없다. 반경 수에서 제외하되 **서울 원천 전체 미위치 건수**를 별도 안내한다.86건을 선택 반경의 누락 수로 표기하지 않는다.

## 5. 지도·밀도·표시 정보

### 표시

기존 MapLibre4.7.1의 GeoJSON `circle`/`symbol` layer를 재사용한다. 지도 진입 후 선택 후보가 있고 줌≥15일 때만 학원 모듈·RPC를 활성화한다. 학원 표시 토글은 기본 켜짐을 제안한다. 줌15 미만/지도 미진입 시 학원 신규 요청0이다. 바탕 OpenFreeMap POI는 계속 숨겨 별도 POI를 학원 수에 섞지 않는다.

분야의 원문 키별 고정 palette를 사용한다. 같은 분야는 진한 색+외곽선·범례의 “채점 분야”로 강조하고 다른 분야는 낮은 채도로 표시한다. 색만으로 구분하지 않도록 범례·키보드 선택 목록에도 분야 텍스트를 넣는다. “같은 분야만/전체 분야”는 표시 필터이며 채점식 변경이 아니다. 미기재는 회색, 새 분야 키는 명시적인 미매핑 색·텍스트로 보존하고 자동 분류하지 않는다.

### 겹침

- 서로 다른 좌표를 성능 때문에 격자화/이동/샘플링하지 않는다. 같은 원좌표의 기관은 하나의 위치 점과 **기관 수 배지**로 나타내고 클릭 목록에서 이름·분야·명시 층을 선택한다. 같은 분야가 포함되면 동일 분야 테두리 및 `동일 분야 n/전체 m`을 구분한다.
- 점수의 cluster(집적)와 지도상의 위치 묶음을 같은 개념으로 부르지 않는다. 점 glyph 수가 학원 수라고 표기하지 않는다. 가까운 점의 화면 겹침은 클릭 반경 hit test 결과를 ID로 dedupe하여 선택 목록으로 제공한다.
- DOM Marker를 기관마다 만들지 않는다. 원본4326 좌표는 유지하고 겹침을 풀기 위한 허위 좌표를 저장하지 않는다. 3D 지붕·층 높이를 추정해 띄우지 않는다. 기본2D에서 모든 정보에 접근 가능하게 한다.
- popup을 닫아도 cluster 근거와 후보 선택은 유지한다. Esc·키보드·모바일 탭으로 팝업/같은 위치 목록을 열고 닫을 수 있게 하고 후보 마커 클릭을 가로채지 않는다.

### 층·이름·개인정보

학원명은 원천 공개 **기관명 `PEI_NM`**이다. 사업자 대표자 성명과 다르다. 기관명에 사람 이름이 포함돼도 공식 공개 기관명을 표시하되, 대표자/설립자 성명을 추가 수집·연결·추론하지 않는 정책을 추천한다. 개원 상태와 출처가 확인된 기관명만 표시하며, 제공기관 정정/삭제가 다음 snapshot에 반영되면 지도도 함께 반영한다. 공개 라이선스가 모든 개인 정보 재사용의 포괄 허가라는 설명은 하지 않는다.

층은 명시된 `지하1층`, `2층`, `2~3층` 등만 표시한다. 다층은 복수 값을 보존하고 기관 수는 여전히1이다. `301호`, `B101호`, 건물층수나 후보 층으로 추정하지 않는다. 모호/누락은 `층 미기재`다. 상세주소 전체·호수·전화·대표자·수강생 정보는 RPC/팝업/로그에 싣지 않는다. 이름은 HTML이 아닌 text로 렌더한다. 파싱 원문은 기존 보호된 원본 저장소에서 검산하며 client에는 공개용 층 label만 보낸다.

[v0.4.0 층 집계](../validation/scoring-v040-20261007.md#학원교습소-층-분포)의 파싱 기준/원본을 재사용 가능한지 확인한다. 전용 파서가 없으면 `/ingest`에 순수 파서를 만들고 명확한 주소 층 추출과 모호 사례를 fixture로 고정한다. 이는 건물 높이·노출·층 선호 추정이 아니다.

## 6. 조회·권한·데이터 계약

### RPC와 벡터 타일

| 선택지 | 이점 | 비용·위험 | 판단 |
|---|---|---|---|
| 반경 전체 경량 RPC→GeoJSON | 현행 채점 거리식·snapshot·기관 수를 직접 대조, Supabase 익명 authenticated 재사용 | 밀집 반경 응답·클라이언트 적재 비용 측정 필요 | **추천** |
| viewport RPC | payload 감소 | pan마다 조회, 화면 밖 기관 수와 원시값 불일치, 응답 세대/페이지 복잡성 | 필요하면 후속 검토 |
| MVT 벡터 타일 | 넓은 지역·반복 탐색에 유리 | 타일 중복/클리핑과 기관 총수 분리, generation별 캐시·공개 배포/별도 집계 경로 필요 | 서울 전체 탐색 확장 시 재검토 |

현 범위는 선택 후보 최대5개 중 활성1개의800/1000m 원이다. 서울 전체25,508점을 매번 전송하지 않는다. 줌15의 활성 반경 전체를 한 번 받고, pan/분야 필터는 메모리에서 처리한다. [고정 버전 GeoJSONSource 구현](https://github.com/maplibre/maplibre-gl-js/blob/v4.7.1/src/source/geojson_source.ts)을 재사용하므로 새 지도 라이브러리는 필요 없다.

제안 RPC `academy_layer(lat,lng,radius_m,expected_source_revision)`:

- 새 read-only RPC이며 기존 `compare_map_context`/`score_inputs` 시그니처·권한·반환형은 바꾸지 않는다. radius는800/1000만 허용, 유한한4326 좌표·서울 범위 검증. 후보 ID/주소/임대료/uid를 입력이나 응답에 싣지 않는다.
- `schema_version`, `status`, `center:[lng,lat]`, `radius_m`, `source_revision`, `counts_by_field`, `total_count`, `collection`과 출처/좌표 provenance/서울 전체미위치수를 반환한다. same_field_count는 원문 field로 client가 counts에서 읽어 채점과 비교한다. field를 client에서 임의로 보내 점수 기준을 바꾸지 않는다.
- Feature 속성은 `academy_id,name,field,floor_label`과 필요한 공개 provenance만. 좌표는 채점 `academies.geom`의 충분한 float 정밀도(기존15자리 직렬화)를 보존한다. **RPC 필터링 전에 반올림하지 않는다.** 클릭 상세 때문에 외부 API를 추가 호출하지 않는다.
- `ready`, `outside_coverage`, `coordinate_replacement_pending`, `source_mismatch`, `too_dense` 등을 구분한다. 준비되지 않은 자료는0건 FeatureCollection을 성공으로 위장하지 않는다. 전체 포함을 검증한 경우에만 ready.
- 같은 SQL snapshot에서 기관 목록과 counts를 산출한다. 기존 geography 공간 인덱스를 확인하고 EXPLAIN으로 사용 여부를 검증한다. 단순 geometry BBox만으로 대체하지 않는다.
- 명시 층/원본 해시/표시 가능 판정은 **새 `app_private.academy_display` 파생 테이블**로 두고 기관 ID+revision으로 조인하는 안. 좌표를 이 테이블에 별도 사본으로 두지 않는다. floor가 NULL이어도 기관을 누락하지 않는다. 표시 테이블 미적재·revision 불일치는 데이터 준비 실패로 처리한다.
- 공개용 allowlist projection만 반환하도록 새 function은 고정 빈 search_path·명시 스키마를 쓰고 auth.uid를 확인한다. 필요한 경우 SECURITY DEFINER로 private projection을 읽되 PUBLIC/anon EXECUTE를 revoke, authenticated만 허용한다. 직접 private table 접근은 허용하지 않는다. 기존 개인 후보/비교 RLS를 변경하지 않는다. 두 uid에서 같은 공개 입력의 응답은 같아야 하며 타 uid 개인 자료는 응답하지 않아야 한다.
- client 요청1개 동시 실행, 후보 전환250ms debounce/이전 요청 abort·세대검증. cache는 메모리 최근5개, 중심/반경/원천revision 기준, 변경/재계산 시 폐기. 최초 기대 revision이 없으면 검증 가능한 입력 확보 후 요청한다. 디스크·service worker의 장기 자료 캐시는 추가하지 않는다.

기존 객체 변경 여부(예정): **RPC/표시 테이블·권한은 신규 추가, 원천·기준분포의 데이터 교체와 월간 loader 수정은 PR G의 별도 승인 범위. 기존 함수 교체·DROP은 계획하지 않음.** 실제 migration은 CLI로 생성하고 최종 diff·영향 행수·dry-run 후 push 승인을 받는다. 필요한 메타 확장이 발견되면 이 설명을 먼저 고친다.

## 7. 밀도·성능·번들 예산 제안

아래는 측정 결과가 아닌 **구현 승인 시 사용할 통과 기준 제안**이다. 원격 컴퓨트는 현재 Micro, Small 전환/공개 전 합본 조건은 별도 유지한다.

| 항목 | 예산·검증 |
|---|---|
| DB | a/b/c 및 서울 학원밀도 최대 셀,800/1000m 직접SQL EXPLAIN ANALYZE 각30회. 첫 실행/웜 분리. 웜p95≤300ms 목표,1,000ms를 넘으면 최적화안 보고 후 중단 |
| RPC 응답 | 최대 실측 반경 기준 raw≤1.5MiB, gzip≤256KiB. Content-Encoding·전/후 bytes를 각각 기록, 압축이 없으면 gzip실측이라고 표현하지 않음 |
| HTTP→첫 점 표시 | 익명 authenticated 실제 Preview/production 경로, 콜드/웜 분리. 콜드≤3초·웜p95≤1초 목표, 3초초과/timeout은 원인·개선안 보고 |
| 밀도 | 실제 최대 셀 + 합성5,000기관의 동일좌표/다른분야/미기재 fixture. 5,000기관은 검증 크기이며 생산 LIMIT가 아님. 더 많은 실제 입력이면 전수 표시 성능을 추가 측정 |
| 보호 상한 | 실제 분포를 확인해 최대 응답 상한을 승인한다. 넘으면 too_dense 안내·보고. LIMIT로 조용히 잘라 N과 맞지 않는 지도를 내보내지 않음 |
| 조작 | 준비 후 점/범례/근거 선택p95≤100ms,max 기록. 슬라이더100회×3세트: CI중앙값≤100ms, production각세트≤100ms 유지 |

| 미진입 비용 | 지도 미진입 또는 줌15미만에서 학원 모듈·RPC0. 2D만 사용 시3D/deck 요청0. 모바일은 기존 ExposureOverlay 미진입 유지 |

학원 source는 가중치 조작 때 다시 setData하지 않는다. 변경 시점은 중심/반경/원천revision/필터이며 선택은 feature-state를 우선한다. 좌표 해상도 축소·기관 삭제·샘플 수 제한으로 성능 통과를 만들지 않는다. 예산 초과 시 GeoJSON 속성 최소화·전송 압축·캐시·쿼리·색인부터 검토하고, MVT 전환은 새 제안으로 보고한다.

- 기존 객체 변경 여부: **신규 private 테이블 2개·공개 RPC 1개·신규 객체 권한만 추가. 기존 테이블/함수/트리거/데이터 변경·DROP 없음.** 로컬 격리 DB 적용·local dry-run exit 0. 원격 dry-run도 이력 조회가 필요하므로 원격 읽기 금지 해제 전 보류한다.
- 800m 목표: SQL 웜 p95 ≤300ms, raw ≤1.5MiB, gzip ≤256KiB. 합성 1,500기관 단독 측정 SQL p95 17.203ms, raw 563,058B, 오프라인 gzip 36,285B. 5,000기관은 완성 응답이 1,870,056B여서 `too_dense`로 닫으며 LIMIT로 일부 점을 정상처럼 표시하지 않는다. 로컬 합성 결과는 Micro 실제 밀집 지역 검증을 대체하지 않는다.
- [검증](../validation/academy-layer-a-20261016.md), [RPC 계약](data-sources.md#학원-점-레이어-rpc--a-합성-계약-2026-10-16), [승격/롤백 인계](../operations/academy-layer.md)를 따른다. **A Ready는 G 원격 승격·실제 원천 대조 이후**다. B는 합성 fixture로 지도·분야 강조·N/M·팝업/보류 배지·근거 연동을 개발할 수 있다.

## 2026-10-16 G 보완 결정 — 학교 표준 좌표와 품질 보류 표시

신규 사용자 등록의 Juso 좌표 전환은 별도 PR에서 구현하며 기존 Vworld 저장 데이터는 목록·교체 계획만 작성한다. #39는 학교 네이티브 좌표 검토와 기존101행의 품질 플래그 계획을 반영한다. 원격 쓰기·삭제 금지, 해외 저장 회신 대기, G 승격 뒤 A/B Ready 순서는 유지한다.

### 학교 공급자 채택 — 2026-10-16 사용자 승인, 로컬만 적용

[공식 표준데이터 검토](../validation/school-standard-review-20261016.md) 후 한국교육시설안전원 위치 표준데이터를 채택했다. **기존 Juso 좌표 1,241행은 전부 유지**하고, 미확보 79행 중 학교명·급·도로명주소가 일치하며 서울 경계 안인 **73행만 보완**한다. 기존 제안의 안전 연결 1,302행 전량 대체는 실행하지 않는다. 결과는 1,314/1,320(99.55%), 미확보 6행이다. 학교 명부·이름·급·NEIS ID는 계속 NEIS다.

기존 `public.schools.geocode_provider`에 `juso` / `edu_facility_standard`를 구분한다. 공급자 SCHOOL_ID·기준일·원본 SHA·NEIS crosswalk는 로컬 snapshot manifest와 `ingest_private.place_snapshots.report.school_coordinate_supplement`에 보존한다. 경계 밖 표준점의 태강삼육초·한국삼육고, 표준↔Juso 538.2m의 화랑초는 Juso 좌표를 유지하고 `geocode_reason`의 `coordinate_verification_pending:` 접두사로 보류 표시한다. 이 플래그는 결측이 아니므로 `geocode_failed=false`를 유지한다. 향후 지도/근거는 이를 `좌표 검증 보류`로 표시하며 채점 제외·신뢰도 감점은 하지 않는다.

제공기관 파일 메타에는 좌표계 명시가 없다. 승인된 판단 절차에 따라 동일 학교 1,229교의 Juso 대조(중앙값72.7m·최대538.2m, 일률 편이 없음)를 근거로 **EPSG:4326으로 판정**했다. 공식 EPSG 선언으로 표현하지 않는다. 동서/남북 오차 분포와 메타 원본 해시는 [보완 검증](../validation/school-supplement-20261016.md)을 따른다.

`ingest/supplement_school_coordinates.py`로 격리 로컬 DB에만 적용하며 학교 원천·출처·보류 사유·기준 분포는 같은 트랜잭션으로 반영한다. migration은 없고 기존 컬럼/테이블만 사용한다. 전후 10테이블 binary snapshot과 로컬 학교 Parquet·기준 분포를 보존하고 rollback→재복원 digest를 검증한다. 원격 승격·push·카카오 캐시/키 삭제는 금지 상태다. Juso 해외 저장 공식 회신과 별도 승인을 기다린다. Juso 학교명/상세주소/건물관리번호 추가 조회는 잔여 6행의 공식 주소 확인 후 필요한 경우만 제안한다.

### 기존 >500m101행의 표시 계약 (계획)

- 대상은 기존 고정 검토 manifest의 **학원99행·학교2행**이며, 행 ID+source snapshot으로 정확히 연결한다. 단순히 주소가 같거나 새 이동거리가 크다는 이유로 대상 ID를 확장하지 않는다.
- 품질 필드 제안: `coordinate_quality='verification_pending'`, `coordinate_quality_reason='moved_over_500m'`, `quality_review_version='20261014-v3'`. 플래그 원본은 기존 검토 manifest와 연결한다. 공급자와 품질 플래그는 별개다. 다른 PNU46행의 분류(같은 건물27/다른 건물1/판단불가18)도 보존하되 전부 같은 오류/보류 원인으로 덮어쓰지 않는다.
- **지도 팝업:** 학원명·분야·주소 명시 층의 기존 표시 범위에 `좌표 검증 보류` 배지와 `기존 좌표에서 500m 넘게 이동해 위치를 확인 중입니다` 문구를 추가한다. 구/신 좌표·원주소 전체·개인 사업자 정보는 팝업에 추가하지 않는다.
- **cluster 근거:** 동일 분야 반경 집합N에 포함된 보류 기관 수K를 `N곳 중 K곳 좌표 검증 보류`로 표시하고 항목→지도 강조를 유지한다. 줌/viewport로 바뀌는 M과 구분한다. 중첩점은 기관 수로 센다. 99행 전부가 각 후보의 동일 분야/반경에 속하는 것은 아니다.
- 학교2행은 학원 점으로 그리지 않는다. 학교 표시/관련 demand·environment 근거에서 동일 보류 배지를 전달하도록 계획한다.
- **점수 유지:** 보류는 오매칭 확정이 아니다. 플래그만으로 기관을 제외하거나 신뢰도/가중치/cluster 정규화를 바꾸지 않는다. 제외 결정은 별도 사용자 승인 후 원천/분포를 함께 갱신한다. 따라서 N/점수 입력/지도 집합의 일치를 유지한다.
- 테스트: 보류 기관이 반경·동일 분야 집합에 들어가는/빠지는 경우, 겹친 마커, 분야 변경, 800/1000m, 학교를 학원으로 세지 않음, 팝업·근거 동일K, 보류0일 때 불필요 문구 없음. source ID가 바뀌면 자동 해제하지 않고 검토 필요를 보고한다.

이번 커밋은 표시 계약/학교 공급자 제안 문서만 추가한다. 품질 열/RPC/UI 구현과 학교 좌표 교체는 수행하지 않았다. G의 최종 원격 승격에는 업데이트된 manifest와 별도 승인, Juso 해외 저장 공식 회신이 필요하다.
