# 길목(GILMOK) 화면 정의 — screens.md

> 작성일: 2026-09-26 · 버전: **v0.1 (S3 구현 승인 대기)**
> 기준 문서: `docs/planning/location-simulator.md`(S3 인계 절), `scoring-spec.md` v0.3, `data-sources.md` §3 (입력 계약 v1.3)
> 채점 출력: `ScoreResult` (lib/scoring/types.ts 현행), 노출 모델 0.2.2 (`exposure_inputs_v022`)
> 상태: 화면 구조·상태 흐름·기술 결정은 확정, 시각 디테일(색·타이포·간격)은 구현 중 조정.

---

## 0. 원칙

1. **2D만으로 의사결정이 끝나야 한다.** 3D는 켜지 않아도 모든 정보에 도달할 수 있다. 3D는 "왜"를 보여주는 보조 뷰다.
2. **점수보다 근거.** 총점은 크게 보이되, 한 번의 클릭 안에 축별 근거(원시값·백분위·적용 규칙·결측 사유)가 있다. 신뢰도는 총점 옆에 항상 붙는다.
3. **결측은 숨기지 않는다.** NULL 축은 회색 "평가 불가"로 표시하고 이유를 쓴다. 재배분 사실도 근거에 보인다. 0점처럼 보이게 하지 않는다.
4. **비로그인으로 끝까지 간다.** 진입 시 익명 인증(Supabase anonymous sign-in)으로 uid를 받고, 저장·공유 시점에만 이메일 연결을 요구한다. 로그인 화면은 없다.
5. **채점은 브라우저에서.** `score_inputs`·`exposure_inputs_v022`·`score_reference_distribution` RPC를 호출하고 `/lib/scoring` 순수 함수와 Web Worker로 채점한다. Edge Function 채점 API는 MVP에 없다.
6. **모바일에서 카드만으로 완결.** 창업자는 중개사와 현장에서 폰으로 본다. 지도는 모바일에서 탭 하나로 물러난다.

## 1. 화면 목록과 흐름

```

                                   ▲                              │
```

| 코드 | 화면          | 경로                      | 목적                                                            |
| ---- | ------------- | ------------------------- | --------------------------------------------------------------- |
| L    | 랜딩·검색     | `/`                       | 첫 주소를 입력시킨다. 배경은 서울 골든타임 생활인구 맥동        |

| S    | 공유 리포트   | `/r/[id]`                 | 저장된 비교를 읽기 전용으로 본다. 링크 공유용                   |

## 2. [L] 랜딩·검색

### 2.1 구성

- 화면 전체를 어두운 서울 지도가 채운다. 위에 250m 격자 생활인구 맥동 레이어(§2.2).
- 중앙에 검색창 하나. 플레이스홀더 "학원을 열고 싶은 건물 주소". 아래에 한 줄: "서울 · 학원업 · 후보지 최대 5곳 비교".
- 검색창 아래 작은 링크: "예시로 보기" → 대치동 3곳(역삼로 460 3층 / 도곡로 409 2층 / 역삼로 546 3층)이 채워진 [C]로 이동. 첫 방문자가 결과 화면을 먼저 보게 하는 장치.
- 하단 좌측에 데이터 출처 표기(공공누리 1유형 소스 목록으로 가는 링크).

### 2.2 배경 애니메이션

- **데이터:** `living_pop` 800m 아님 — 격자 원본 그대로. 서울 10,127셀 × 평일 시간 15~22시(8프레임) 총합 인구. 월간 갱신 워크플로우에서 정적 JSON(`public/data/landing-pulse.json`, 셀 중심 좌표 + 8개 값, ~300KB gzip)으로 굽는다. 런타임 RPC 호출 없음.
- **표현:** deck.gl `ScatterplotLayer` 또는 `HeatmapLayer`. 프레임마다 반지름·불투명도가 인구에 비례해 커지고 작아진다. 8프레임을 1.5초 간격으로 순환, 프레임 사이는 보간. 채도 낮은 단색(호박색 계열), 지도 배경은 거의 검정.
- **정직성:** 화면 구석에 "평일 15~22시 생활인구, 250m 격자" 라벨. 이동 방향·화살표는 그리지 않는다(데이터에 없음).
- **성능:** 데스크톱(≥1024px)에서만 재생. 모바일과 `prefers-reduced-motion`은 같은 데이터로 미리 렌더한 정지 PNG. 지도 라이브러리는 검색창 첫 렌더 뒤 lazy-load. 애니메이션은 `requestAnimationFrame`, 탭 비활성 시 정지.

### 2.3 동작

- 주소 입력 → Kakao 주소 검색 자동완성(서버 라우트 경유, 키는 서버에만). 선택 시 [R]로 이동하며 주소·좌표를 넘긴다.
- 잘못된/서울 밖 주소: "지금은 서울만 지원합니다" 인라인 안내. 진행 불가.
- 진입 시 익명 세션이 없으면 `signInAnonymously`. 실패해도 검색은 가능하되 저장 불가 상태로 표시.

## 3. [R] 후보지 등록

### 3.1 입력 폼

| 필드                        | 필수 | UI                                              | 검증                                                                      |
| --------------------------- | ---- | ----------------------------------------------- | ------------------------------------------------------------------------- |
| 주소                        | 필수 | [L]에서 넘어온 값, 수정 가능                    | 서울 내 도로명·지번                                                       |
| 층                          | 필수 | 숫자 스테퍼, 지하는 음수(−1)                    | −5 ~ 30                                                                   |
| 전용면적 (㎡)               | 선택 | 숫자                                            | 500 이상이면 교육연구시설 안내 문구 노출(R2)                              |
| 보증금 / 월세 / 관리비 (원) | 선택 | 숫자 3개, 접힌 섹션 "임대료 입력하면 효율 비교" | 임대료 축은 v0.3에서 lo/hi 미확정이라 점수 없이 근거만 표시됨을 폼에 명시 |
| 별칭                        | 선택 | 텍스트, 기본값은 도로명 주소 축약               | 20자                                                                      |

- 후보지가 이미 5곳이면 "하나를 지우고 추가" 안내.
- 같은 주소·층 중복은 경고 후 허용(층만 다르면 별개 후보).

### 3.2 등록 시 일어나는 일 (상태 머신)

```
draft ─등록─▶ fetching ─RPC 3종 완료─▶ scoring ─순수 함수·Worker─▶ scored
                 │                                                  │
                 │  building_lookup.status ∈ {pending, processing}  │
                 └──────────────────────────▶ scored_provisional ◀──┘
                                                    │ Realtime: 캐시 ready
                                                    ▼
                                                  scored
                                                    │ 3분 내 미도착
                                                    ▼
                                            scored_provisional (지연 표시)
```

- `fetching`: `score_inputs(800)`, `score_inputs(1000)`, `exposure_inputs_v022` 병렬 호출. 카드는 스켈레톤.
- `scoring`: 백분위는 `score_reference_distribution` RPC로 축별 raw를 보내 받는다(클라이언트에 분포 전체를 내리지 않음). exposure는 Worker.
- `scored_provisional`: 건물 축만 "확인 중" 스피너, 총점에 "잠정" 배지. 다른 축은 정상 표시. `building_lookup` 캐시 테이블을 Realtime으로 구독하고 ready 시 building 축만 재계산 → 총점 갱신 애니메이션(숫자 카운트업 400ms).
- 3분 타임아웃: 스피너 대신 "건물 정보 확인 지연 — 나중에 다시 열면 반영됩니다". 후보지 저장 시 pending 상태도 함께 저장.
- 실패(RPC 오류·서울 밖 좌표·도형 없음+주소 실패): 카드에 오류 사유, 재시도 버튼.

### 3.3 큐 남용 방지

- 주소 큐 insert는 익명 uid당 **일 10건**. 초과 시 폼에서 "오늘 등록 가능한 새 주소를 모두 썼습니다". RLS 정책 + 트리거로 서버에서 강제.

### 4.2 비교 매트릭스

- **행 = 축 8개 + 총점 행(맨 위, 고정).** **열 = 후보지(최대 5).** 열 순서는 총점 내림차순이 기본, 드래그로 고정 가능.
- **각 축 행 머리에 가중치 슬라이더.** 0~40, 기본값은 프리셋. 드래그 중 `reweight()`로 즉시 재계산(RPC 재호출 없음). 총점 행 숫자가 실시간으로 바뀌고 열 순서는 드래그를 놓을 때 재정렬(드래그 중 정렬은 어지러움).
- 셀: 정규화 점수(0~100) 큰 숫자 + 아래 작은 회색 원시값 요약(예: "학원 1,070곳", "역 817m"). 셀 배경은 행 안에서 상대 순위에 따라 3단계 톤(1위 진하게). 절대값이 아니라 **행 내 비교**를 돕는 색.
- 결측 셀: 회색 "—", 호버/탭 시 `missing_reason` 한글 문구. 총점 행에 "N축 재배분" 작은 표시.
- pending 셀(건물): 스피너 + "확인 중".
- 총점 셀: 숫자 크게, 옆에 신뢰도 링(0~100, 작은 도넛). 링 클릭 → 근거 패널에 `confidence.reasons` 전체 목록.
- 집적 행 셀에 포화 배지: low/mid/high, high면 주황. 호버 시 "학생 1,000명당 학원 N곳, 서울 상위 X%" + 외부 통학 수요 한계 문구.
- 건물 행 셀에 `academy_eligible` 배지: true 초록 "등록 가능 용도" / false 빨강 "등록 불가 위험" / null 회색 "확인 필요". R6 걸리면 "유해업소 동거 — 확인 필요" 별도 표시.
- 열 머리(후보명) 클릭 → 그 후보를 선택. 지도가 해당 위치로 이동, 근거 패널이 그 후보 전체 축으로 전환. 열 머리 우측 "···" → 이름 변경·삭제·층 변경(층 변경은 재채점).

### 4.3 지도 (2D)

- MapLibre GL + OpenFreeMap 벡터 타일(liberty 계열 스타일을 톤 다운). 한글 라벨.
- 레이어: 후보지 마커(열 순위 번호 표시, 선택 시 확대), 선택 후보의 800m 반경 원(반투명), 1.2km 내 역 마커, 1km 내 학교 마커(초·중·고 아이콘 구분), `academies` 점(입시·보습만, 작은 점, 줌 15 이상에서만).
- 마커 클릭 = 열 선택과 동기화.
- 우상단 토글 `2D | 3D`. 기본 2D. 로컬스토리지에 마지막 선택 기억.

### 4.4 지도 (3D)

- 토글 시 카메라 pitch 0°→55°, bearing 유지, 선택 후보로 flyTo(줌 17). 600ms.
- `buildings_in_radius` 1km 도형을 `fill-extrusion`으로. 높이 = height_m(unknown은 4m, 반투명 회색으로 구분). 선택 후보 건물은 강조색.
- **노출 샘플점 오버레이**: 워커 결과의 링 108점(20·40·60m × 36방향)을 deck.gl `ScatterplotLayer`로 1.5m 높이에 뿌린다. 가시 = 밝은 초록, 차폐 = 어두운 빨강, 이동된 점은 테두리. 후보 건물 외벽 목표점(층 높이)에 작은 마커. 이게 "간판이 어느 방향에서 보이나"를 유일하게 보여주는 뷰.
- 역·학교 첫 노출 거리(근거 전용)는 해당 마커 툴팁에 "이 역에서 오는 길 최초 노출 약 160m".
- 성능: 건물 4,000~5,000개 익스트루전은 MapLibre 기본으로 60fps 가능. 뷰포트 밖은 소스 레이어 필터로 컬링. 모바일 3D는 지원하되 샘플점 오버레이는 끔.
- 안내 문구(지도 하단 고정): "건물 배치 기준. 가로수·가로시설물·간판 크기 미반영 — 현장 확인 필요".

### 4.5 근거 패널

- 기본 접힘(높이 0), 셀 클릭 또는 후보 선택 시 펼침(뷰포트 35%).
- 셀 클릭: 그 축·그 후보의 `evidence` — 원시값 표, 백분위와 기준 모집단 크기, 적용 규칙 목록(`rules_applied`), 노트. 백분위 축은 서울 분포 위 위치를 작은 히스토그램 스트립으로.
- 후보 선택: 8축 전체를 아코디언으로 + 신뢰도 사유 목록 + 데이터 기준일(`meta.sources`).
- 건물 축: `all_floors` 표(층·용도·면적) 그대로 보여준다. 학원 창업자가 실제로 궁금한 "같은 건물에 뭐가 있나".
- 임대 축: 사용자 입력 임대료가 있으면 ㎡당 환산, 동·층 매매 중앙값(있으면) 참고 표시. 점수는 "v0.3 미확정" 문구.

### 4.6 프리셋·가중치

- 상단 프리셋 드롭다운: "학원 v0.3(기본)" 하나. 슬라이더를 건드리면 "학원 v0.3 · 수정됨"으로 바뀌고 "프리셋으로 저장"이 활성화(익명 uid에 저장, 이름 입력).
- 초기화 버튼은 기본 프리셋으로 복귀.
- 가중치 변경은 신뢰도를 바꾸지 않는다(reweight 계약 그대로).

### 4.7 저장·공유

- **저장**: 익명 uid로 `candidates` + 비교 세트(`comparisons` 테이블 신설: id, user_id, candidate_ids[], weights, preset_id, created_at) 저장. 익명 상태에서도 저장은 되며, 브라우저를 바꾸면 사라진다는 안내를 첫 저장 때 한 번 보여준다.
- **공유**: "링크 만들기" → 이메일 연결 요구(익명 uid를 이메일 계정으로 승격, magic link). 승격 후 `/r/[id]` 공개 읽기 링크 생성. 공유된 비교에는 사용자 임대료를 **포함하지 않는다**(RLS로 강제, 리포트 뷰는 임대 축을 항상 "비공개"로).

### 4.8 모바일 레이아웃 (<1024px)

- 상단 탭 3개: **비교 · 지도 · 근거**.
- 비교 탭: 후보지별 카드가 세로로. 카드 = 별칭, 총점(크게)+신뢰도 링, 8축을 가로 막대 8줄(축명·점수·막대). 카드 상단 스와이프로 순서 비교. 가중치 슬라이더는 카드 위 "가중치" 시트(바텀시트)에서 조정.
- 지도 탭: 전체 화면 지도, 하단에 후보 칩 가로 스크롤. 2D/3D 토글 유지.
- 근거 탭: 선택 후보의 아코디언.
- 3D 샘플점 오버레이는 모바일에서 끔(§4.4).

### 4.9 빈 상태·오류

- 후보 0개: 매트릭스 자리에 "주소를 입력해 첫 후보를 등록하세요" + [+ 후보 추가].
- 후보 1개: 매트릭스는 정상, "비교하려면 후보를 더 추가" 힌트.
- 전체 RPC 실패: 배너 "데이터 서버에 연결할 수 없습니다" + 재시도. 로컬스토리지의 마지막 결과가 있으면 읽기 전용으로 표시.
- 서울 밖·건물 미적재 지역(강남구 외): exposure·building 축 결측, 근거에 "이 지역은 건물 데이터가 아직 없습니다(강남구만 적재)". 총점은 계산됨(§6 규칙).

## 5. [S] 공유 리포트

- `/r/[id]`, 읽기 전용, 로그인 불필요.
- 구성: 제목(비교 이름), 생성일·데이터 기준일, 매트릭스(슬라이더 없음, 저장 당시 가중치 고정 표시), 2D 지도 정지 이미지 또는 인터랙티브(가벼운 쪽으로 구현 시 결정), 후보별 근거 아코디언, 하단 출처·한계 문구(가로수 미반영, 인구 추정, 임대동향 비활성 등 `confidence.reasons` 합집합).
- 임대 축은 항상 "비공개".
- 인쇄 CSS(A4 세로 2~3장). PDF 내보내기 버튼은 브라우저 인쇄로 대체(MVP).
