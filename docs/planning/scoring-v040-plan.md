# academy_v0 v0.4.0 채점 변경

2026-10-07 사용자 요청. base `main`, 브랜치 `s3/scoring-v040`. 문서와 코드는 별도 커밋으로 관리한다.

## 승인된 범위

- R3·R4를 층×승용승강기 표로 대체하고 시작점60, R1+R5 합산 가점 상한30을 적용한다. 지하는 R7−25만 적용한다.
- exposure의 가시 비율에 주목도 Y(1/0.9/0.8/0.7)를 적용한다. 실측이 아닌 모델 가정이며 X(1/0.85/0.7/0.6)는 문서상 대안으로만 남긴다.
- a·b·c·d(역삼로460 4층)·e(동일 건물1층), 고정 무작위5셀을 재계산한다. e−a≥1.5점을 제품상 통과 기준으로 기록한다.
- 근거 패널에서 층·승강기 행, 보정 점수, 원래 가시 비율, 적용 주목도 계수를 확인할 수 있게 한다.
- 주차는 보류 목록만 기록하며 이번 점수에 넣지 않는다.

## DB 변경 없음과 호환 범위

마이그레이션·원격 DB 쓰기·원천 적재·기준분포 재생성 없음. 기존 DB의 `save_comparison`은 비교 metadata에 `preset_version=0.3`을 기록하고, 명명 가중치 테이블도0.3만 허용한다. 이 값은 이번 PR에서 바꾸지 않는다. 저장 내용은 점수 자체가 아닌 후보 입력과8축 가중치이므로 클라이언트는 이 기존 저장 형식을 읽어 v0.4.0으로 새로 채점한다. UI의 계산 버전은 ScoreResult의0.4.0이다. DB의 고정 metadata를 최신 계산 버전으로 해석하지 않는다.

실시간 재채점 실패 시 v0.3 점수 스냅샷을 v0.4.0으로 표시하거나 슬라이더에 재사용하지 않는다. 같은 uid·입력 서명·현재 모델 버전이 모두 일치한 스냅샷만 기존 읽기 전용 복구 대상으로 유지한다.

## 경계 조건·리스크

- 승용승강기 NULL: 사용자 추가 결정에 따라1층·2층·지하는 표대로 적용/차감 없음, 3층 이상만 보정0·신뢰도−5·“승강기 미확인(대장 값 없음)”. 대장pending은60·−15를 유지한다. 비상용 대수로 승용 대수를 대체하지 않는다.
- 지하층 Y 계수는1.0으로 기존 exposure를 유지하고 building에는 R7만 적용한다.
- 승강기NULL·지하층 처리는 사용자 추가 결정으로 확정했다. 지하 근거에 “지하: 입구 간판 기준 노출”을 표시한다.
- 대장 pending·층 용도 미확인의60점 보류, 건물/적재범위 결측 처리, 다른 가감점과 신뢰도는 유지한다.
- 1.5점은 사용자 정의 제품 기준이며 통계적 유의성을 뜻하지 않는다. 5개 기준점으로 전체 지역/업종에 일반화하지 않는다.
