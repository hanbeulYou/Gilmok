# S3-2 A WIP — 백분위·위치 RPC와 순수 함수 어댑터

2026-09-30. **A 전체 완료가 아니다.** 사용자 지시에 따라 문서 변경과 독립 DB/RPC/어댑터를 먼저 커밋했다. 카카오 응답 저장 정책의 충돌은 [별도 조사](s3-2-a-kakao-policy-20260930.md)에서 보고했고, 검색·캐시·후보 저장 경로 변경 결정을 기다린다. 등록 UI·uid별 검색 쿼터·상태 투영은 아직 구현하지 않았다.

## 구현·보존

- `score_reference_percentiles(preset_id,radius,raw)`는 raw 최대7개에 대한 백분위·모집단·coverage 계산용 개수·원천 메타데이터·20bin 집계만 반환한다. 기존 전체 분포 RPC는 유지한다.
- `ScoringReference`는 기존 분포 타입과 compact 응답 타입을 모두 지원한다. `score()`·`reweight()` 수식·가중치·프리셋·신뢰도는 변경하지 않았다. 같은 메타데이터 검증을 사용하고 다른 raw의 응답 재사용을 거부한다.
- `resolve_candidate_location`은 PNU·도형 포함·서울 경계 context를 읽기 전용으로 조회한다. 도형 없음/겹침/PNU 불일치를 구분하고 후보 좌표를 중심점으로 치환하지 않는다.
- 두 신규 RPC는 authenticated/service_role만 호출한다. 기존 anon 조회 계약은 보존하며 테이블/원천 행·R2 객체 변경은 없다.
- 마이그레이션 두 개 모두 Supabase CLI로 생성했다. 로컬 적용·검증만 수행했고 원격에는 적용하지 않았다. 롤백은 새 호출 경로 사용을 중지하고 신규 RPC 권한을 회수하는 방식이며 원천 복원이 필요하지 않다.
