## 변경과 실제 응답

### flow: 관측 격자 합산

시간별 total 비NULL 격자만 EPSG:5186 교차 면적 비율로 합산한다. 비공개를 0명으로 채우거나 커버리지로 나누어 부풀리지 않는다. 유효 격자 0개인 시간은 NULL, 15~21시 7시간 모두 값이 있을 때만 골든타임 평균을 반환한다. `flow.low_coverage`는 평일/주말 24시간 중 하나라도 유효/전체 격자 비율이 80% 미만이면 true다. 전체 격자 0개도 true이며 그 비율은 NULL이다.

대치 좌표 `(127.063642,37.494612)`, 500m, 2층에서 전체 21개, 시간별 유효 17~20개, 최소 커버리지 80.9524%. `low_coverage=false`. 골든타임 평일 **29,365.5457143935명**, 주말 **28,288.519312634명**. 전체 시간별 수·비율은 [실제 응답](pr7-score-inputs-example.json)에 있다. 이는 관측 격자의 합계이며 반경 전체의 완전 관측 인구라고 해석하지 않는다.

## 성능·실행계획·검사

고정 대치·학여울·한티 × 500m/1km × 2층. 각 3회 준비 호출 후 **30회 DB EXPLAIN**, **30회 HTTP**, 각각 180회. DB는 anon 역할, HTTP는 로컬 PostgREST anon 인증. nearest-rank p95(30개 중 29번째), 준비된 캐시 조건이며 HTTP는 합격 조건이 아니라 기록이다.

| 좌표 | 반경 m | DB p95 ms | HTTP p50 ms | HTTP p95 ms | HTTP max ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 대치 | 500 | 19.958 | 23.905 | 24.874 | 77.955 |
| 대치 | 1000 | 59.723 | 63.347 | 65.200 | 65.292 |
| 학여울 | 500 | 15.622 | 19.892 | 21.586 | 23.033 |
| 학여울 | 1000 | 42.629 | 47.137 | 48.966 | 50.846 |
| 한티 | 500 | 28.280 | 33.192 | 34.916 | 35.345 |
| 한티 | 1000 | 88.994 | 89.379 | 95.056 | 96.178 |

6조합 모두 DB p95 <1,000ms다. 원천 행 수는 전후 동일하고 DB 크기는 424,750,227 → 424,881,299 byte였다. 롤백 테스트·통계/페이지 공간도 포함한 관측값이며 용량 통과 기준이나 순수 원천 증가량으로 해석하지 않는다. VACUUM·원격 DB 변경은 하지 않았다.

묶음별 실제 저장 SQL을 추출해 RPC 응답 일치 확인 후 EXPLAIN ANALYZE했다. 각 묶음은 최종 한 행을 만든 뒤 결합한다. 대용량 공간 소스에는 GiST/PK 범위 조회를 사용하며 building의 대장 연결은 PK당 최대 한 행이다. 대치 500m 건물은 공간 필터 후 300행→품질 집계 한 행, 대장 PK 인덱스 300회 조회로 증폭이 없었다. 소스 기준일 조회에는 LIMIT 1 아래 Seq Scan이 나타나지만 실제 1행에서 멈췄다(건물은 SHP/WFS별 1행). 작은 메타데이터·14개 법정동 등의 Seq Scan은 허용하고 큰 원천 전체 스캔·다대다 증폭·임시 디스크 spill은 발견되지 않았다. flow/높이 품질은 별도 직접 SQL oracle과도 대조했다.

- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:db` 통과: Vitest 1, Python 205, DB 118.
- 한 묶음 결측 시 나머지 6개 정상 반환, 부분 격자 합계, 80% 경계/60% low_coverage, 무관측 시간 NULL, 주소 캐시 적중·만료/정확한 층, anon/authenticated 큐 이용과 private 차단, 제외 건물의 렌더링 유지 포함.
- 새 마이그레이션 3개를 CLI로 생성·로컬 적용했다: `20260921065136`, `20260921065937`, `20260921070105`. 기존 적용 파일은 수정하지 않았다. 원복 필요 시 별도 CLI 마이그레이션으로 이전 함수 정의를 복구하고 캐시/원본은 보존한다. 주소만 끄려면 호출의 address를 생략할 수 있다.
