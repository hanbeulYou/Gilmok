- 주 반경 800/1000m, 학교 반경 1000m, 층 2. 서울 경계 context는 admin_dongs 합집합의 exterior ring까지 geography 거리이고 ST_Covers로 서울 포함을 확인했다. 법정동명은 code8/name 표를 주입했다.

## 역삼로460과 R6

- 동일 PK 1024123872의 표제부 gross_area는 **849.97㎡**이고 요청 층 용도 면적 **173.68㎡**와 다르다. footprint·주소 캐시 두 실제 경로 모두 3층 building=100, 4층 building=90을 확인했다. 실제 응답은 [v1.3 예시](score-inputs-v13-example.json)에 있다.
- 3층: 60+R1 25+R4 10+R5 15=110 → 100. 4층: 60+25−R3 15+R4 5+R5 15=90. 같은 층의 중복 용도, 요청 층·옥탑·미상 제외와 승강기 NULL/0, 6층 R3 비중복을 테스트했다.
- R6는 사용자 승인 규칙으로 유해 키워드 관측 시 −40, gross_area<1650이면 false, ≥1650/NULL이면 NULL이다. 1649·1649.999·1650·1651·NULL 테스트 통과. 다른 R1/R2의 false를 R6의 NULL로 덮지 않는다. 실간 거리 계산은 구현하지 않았다. 법령 근거는 채점 명세 §5.6을 따른다.

## 마이그레이션·정밀도·분포 재생성

- CLI 생성 migration 3개: v1.3 gross_area wrapper, 정밀도 보존 reference 읽기 RPC, 주소 NULL 경로 중복 제거. 모두 로컬 적용했고 기존 migration은 수정하지 않았다. 세 번째는 새 주소 payload에 gross_area=NULL이 이미 있을 때 결측 경로가 두 번 생기는 실제 통합 테스트 실패를 고쳤다.
- 주소 워커는 totArea를 보존한다. 기존 캐시는 동일 PK 표제부로 보완하고, 새 캐시에 명시된 NULL은 다른 값으로 덮지 않는다. 해당 공개 대장이 없으면 NULL을 유지한다.
- 일반 테이블 HTTP는 예컨대 1.0986122886681096을 1.09861228866811로 반환해 동률이 깨진다. SECURITY INVOKER/SELECT-only `score_reference_distribution`은 extra_float_digits=3으로 정확한 JSON을 반환한다. **155,815개 비NULL 값 전체의 HTTP vs DB 바이너리 불일치 0**, 6개 좌표/반경 RPC의 7개 묶음도 HTTP/DB 값이 일치했다.
- preset v0.1.2 / inputs v1.3 / snapshot `20260923T111436Z`. 10,127셀×2반경×8지표 **162,032행**, 입력 RPC 20,254회. 수집 354.999초, 게시·재계산·COPY·VACUUM 20.203초, 합계 375.202초. R2 재계산·DB 전수 대조 불일치 0.
- 로컬 DB 전체 적재 전 480,644,243 byte, 직후 522,382,483 byte. 작업 snapshot 임시 파일 포함 1,378,346,946 byte. 기존 500MB 제한은 적용하지 않았고 원격 플랜/데이터 범위를 바꾸지 않았다. [분포 재생성 요약](s2-2-reference-summary.json)에 테이블·인덱스·R2 객체 크기와 해시가 있다.
- 실패 보존·RLS·source fingerprint 검증은 S2-1 경로를 재사용한다. 기존 입력/분포는 R2 revision에 보존한다. 새 계약을 배포하는 동안 구버전 분포를 혼용하면 채점은 결측을 반환하므로 코드·스키마 적용 후 분포 재생성·검증을 완료한 뒤 소비해야 한다. 되돌릴 때에도 새 migration으로 이전 wrapper를 복구하고 같은 계약/preset/source의 이전 분포를 재검증해야 한다.

## PR #13 후속 — 명세 v0.1.3 재검증 (2026-09-23)

사용자 결정으로 백분위 5축 중 2축 이상 결측일 때만 total을 NULL로 둔다(W=0 조건 유지). 규칙 3축 결측은 유효 축으로 가중치를 재배분하고 각 결측 축의 evidence.notes에 안내한다. 지하층은 R4 없이 R7 −25만 적용한다. 외부 API 응답으로 정책을 바꾼 것이 아니다.
