## GitHub 등록 이름

`gh secret list --json name --jq '.[].name'`으로 확인한 14개 이름:

```text
DATA_GO_KR_SERVICE_KEY

SUPABASE_DB_PASSWORD
SUPABASE_DB_URL

```

`SUPABASE_ACCESS_TOKEN`은 사용자가 갱신한 유효 토큰으로 재등록했다. 이번 재확인에서 연결에 성공한 `SUPABASE_DB_PASSWORD`를 다시 등록하고, 확인한 pooler 호스트·프로젝트 ref·URL 인코딩한 비밀번호로 조립한 Session URI(5432, sslmode=require)를 `SUPABASE_DB_URL`로 등록했다. `.env`의 로컬 URL은 등록하지 않았다.

Repository Variable `INGEST_REMOTE_ENABLED=false`를 설정하고 조회로 확인했다. 금지된 `SUPABASE_SECRET_KEY`, `NEXT_PUBLIC_*`, `GITHUB_DISPATCH_TOKEN`은 등록하지 않았다. 값은 이 기록에 포함하지 않는다.

## R2·코드 점검

- R2 원본 목록 조회 성공. 경계·인구·교통·상가·학원·학교·건물·실거래·임대·기준 분포 원본이 있다.
- 학원·학교 원본 Parquet 스키마에는 지오코딩 좌표가 없다. `ingest/verify_commerce_education.py`는 원본 게시 후 `attach_geocodes`로 로컬 공개 주소 캐시를 붙인다. 공개 시설에 한정한 좌표 보완 스냅샷이 필요하다. 이번 점검에서 R2 쓰기는 하지 않았다.
- 기존 Actions 3개 파일은 `vars.SUPABASE_PROJECT_REF`를 참조한다. 요청한 Secret 사용에 맞춰 코드 수정이 필요하다.
- GitHub `ingest-production` 환경은 조회 시 없었다. 웹훅 실제 처리 검증 전에 준비해야 한다.
- 프론트 앱과 Vercel 연결 설정은 아직 없다. Marketplace 환경변수 이름은 공식 문서로 확인했으며 실제 프로젝트 주입은 연결 후 확인한다.
