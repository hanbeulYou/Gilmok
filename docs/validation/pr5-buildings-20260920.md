# PR 5 강남구 건물 실제 적재 검증 — 2026-09-20

기준 `main`(`5b8e095`), 브랜치 `s1/강남구-건물`. 승인된 소스·높이·차폐 계약을 구현하고 로컬 Supabase와 실제 R2에서 검증했다. 원격 Supabase 변경·유료 전환·VACUUM은 실행하지 않았다. 이 기록은 건물 RPC 검증이며 전체 S1 `score_inputs` 완료를 뜻하지 않는다.

## 소스 선택과 원본

사용자 결정: SHP를 주 소스, SHP에 없는 WFS 도형을 보조로 사용한다. 선택 근거는 PNU 100%, 표본의 대장 연결률 우위, CC BY 배포 조건, 주 원본의 API 약관·쿼터 비의존이다. WFS는 대장을 연결하지 않으며 대장 기반 집계에서만 제외한다. **SHP와 WFS 모두 3D 표시·차폐 입력에 포함한다.** 이용조건 관측과 사용자 결정을 구분한 [사전 비교](pr5-footprints-20260920.md), [승인 계획](../planning/pr5-buildings-plan.md)을 따른다.

서울 전체 `AL_D010_11_20260909.zip`(135,736,236 byte)을 압축 해제하지 않고 `/vsizip`으로 직접 읽었다. `.prj`는 EPSG:5186이며 문자 속성은 CP949를 strict 디코딩했다. 원천 29컬럼(A0~A28)과 geometry를 보존한다. DuckDB 드라이버의 OGC_FID는 추가 식별자다. 파일 배포일 2026-09-09, 행 기준일 A22는 2026-09-06이다.

운영: **수동 다운로드 후 R2 raw/에 게시, 갱신 주기 분기**. 서울 원본 695,754행과 ZIP 전체를 보존하며 S1 DB 적재만 강남구로 한정한다. 새 파일 없이 원천 기준일을 갱신하지 않는다.

공간 중복은 EPSG:5186에서 SHP와의 교차 면적이 0.01㎡를 넘으면 제외한다. 경계 접촉·그 이하 수치 오차는 허용한다. WFS ID가 다르다는 이유만으로 같은 위치의 도형을 다시 추가하지 않는다. 이 보수적 규칙은 서로 일부 겹치는 별도 도형도 제외할 수 있으며, 제외 ID·사유와 원본을 보존해 재검토할 수 있다. 제외된 붕괴 도형은 `lt_c_bldginfo.17088516`(127.05338466, 37.49783265)이다.

수리는 원천 좌표계에서 `ST_MakeValid`로 수행했다. SHP 4건은 면적·bbox를 보존하고 Polygon을 유지했다. 적재 geometry는 유효한 MultiPolygon(4326), PNU 누락 0개다. SHP 원본은 수리하지 않았고 도형 단순화도 하지 않았다. WFS는 bbox 전체 73,141 feature ID의 완전한 타일 합집합을 검증한 뒤 시군구 11680을 골랐다(237요청·178말단 타일).

## 건축HUB 수집·연결

14개 법정동·일반/산 21조합에서 `getBrTitleInfo`와 `getBrFlrOulnInfo`를 100행씩 읽었다. 성공 페이지는 표제부 256개·층별개요 2,001개다. 사전 예상 2,255회와의 차이 2회는 정상 0건 조합의 첫 페이지다. 재시도 호출은 별도이며 실제 계정의 일일 잔여 쿼터는 확인하지 않았다.

HTTP 503뿐 아니라 HTTP 200의 빈 본문도 관측했다. 이를 결측으로 저장하지 않고 제한된 재시도/중단 후 캐시 재개로 회복했다. 오류 기록 65개 모두 대응하는 성공 페이지가 있으며 미완료 오류 0개다. 전체 저장 페이지에서 totalCount·pageNo·numOfRows·조회 내 rnum 연속성·동/대지구분을 재검증했고 추가 API 호출은 0건이었다. 제공 API가 시점 고정 스냅샷을 보장한다는 뜻은 아니다.

| 대상 | 결과 |
|---|---:|
| 표제부 | 24,324행, 현행 PK 중복 0 |
| 층별개요 | 198,637행 |
| SHP→표제부 PK+PNU 연결 | 19,016 / 28,227 = 67.37% |
| SHP 원천 PK 없음 | 5,957 |
| 변환 PK에 해당하는 표제부 없음 | 3,254 |
| WFS 의도적 대장 미연결 | 1,885 |
| 층별개요→표제부 연결 | 198,571 / 198,637 = 99.9668% |
| 부모 표제부 없는 층별개요 | 66행, 4개 원천 PK |

현행 22자리 PK는 text로 그대로 보존한다. 구 일련번호는 확인된 `1024`+실대장 `1`+원문 일련번호로 변환하며 **동일 PNU까지 일치할 때만** 연결한다. SHP에 원천 PK가 있는 22,270개 기준 연결률은 85.39%다. 연결된 고유 표제부는 19,016개다. 미연결 원인을 폐말소/신축 등으로 추측해 채우지 않는다.

층별개요는 층 구분·번호·원문 이름·용도·면적·본관/부속을 보존한다. `(건물, 층번호)`로 합치지 않고, 원문 속성 SHA-256+동일 행 출현 순번으로 ID를 만든다. rnum/요청 페이지는 영구 ID에서 제외한다. 부모 없는 66행도 `source_register_pk`와 `title_missing`으로 남기며 대장 집계에서는 제외한다.

## 높이·차폐·대장 집계 계약

| source | 원천 양수 높이 | 층수 추정 | unknown |
|---|---:|---:|---:|
| gis_buildings_shp | 16,652 | 5,596 | 5,979 |
| vworld_wfs_supplement | 0 | 1,712 | 173 |
| 합계 | **16,652** | **7,308** | **6,152** |

원천 높이>0은 그대로 쓴다. 없으면 지상층수×3.3m이며 1층 단층에서 주용도 앞 두 자리 03(제1종 근린생활시설)·04(제2종 근린생활시설)·07(판매시설)은 4m다. 해당 4m 추정은 SHP 124개다. 다른 용도·용도 미상은 3.3m를 쓰며 학원 적합성 판정은 하지 않는다.

높이·층수 모두 없으면 `height_m=NULL`, `height_source=unknown`이다. `render_height_m`/`occlusion_height_m`만 4m이며 `estimated=true`다. `height_estimated`와 `meta.estimated_buildings`는 층수 기반 추정만 가리킨다. RPC의 모든 도형에 `occlusion_included=true`이고 `meta.confidence`는 unknown_count/occluder_count/unknown_ratio를 반환한다(0개면 ratio NULL). 전체 unknown 비율은 6,152/30,112=20.43%다.

`registry`는 연결된 SHP의 고유 표제부 PK만 대상으로 용도·승강기·층별개요를 집계한다. WFS와 미연결 SHP는 포함하지 않는다. 동일 표제부에 도형 여러 개가 연결되어도 표제부를 한 번만 센다. 조회 범위는 현재 적재된 강남구이므로 경계 밖 미적재 도형에 따른 가시성 신뢰도 한계가 남는다.

PR 5는 조회 데이터 계약까지 구현했다. 실제 3D 렌더러·가시성 레이캐스트·점수·학원 등록 가능성은 구현하지 않았으며 후속 스프린트가 이 계약을 사용한다.
