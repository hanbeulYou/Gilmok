# PR 3 버스 미매칭 편중·요일 계약 확인 — 2026-09-19

## 결론

버스 미매칭을 무작위·균일한 누락으로 취급하면 안 된다. 2026년 6~8월 승차+하차 합계 886,937,877건 중 미매칭 41,280,731건, **4.6543%**다. 유형별 누락률 차이가 크고, 서울 외 지역 연결 노선·특정 내부 ID 대역에 편중된다. 이는 관측된 분포에 대한 판단이며 무작위성의 통계적 가설검정을 수행한 것은 아니다.

## 서울 자치구 관련 잔여 편중

서울 위치 자료에서 주로 관측되는 100~124 ID 구간 자체의 누락률은 **0.1413%**이며, 그 누락량 1,196,845건 중 **46.01%**(550,703건)가 113 구간이다. 113 구간 전체의 누락률은 **1.3953%**다.

실제 위치와 행정동 경계를 조인하면 113 구간의 위치 확인 정류장 585개 중 574개는 마포구, 6개 서대문구, 4개 용산구, 1개 중랑구로 나타난다. 따라서 이 구간을 마포구의 정확한 행정경계와 동일시하지 않는다. 미매칭 원천 이름으로는 **홍대입구역(가상)·합정역(가상)**이 두드러진다.

113 구간 미매칭량 중 이름에 `가상`이 있는 행은 532,129건(**96.63%**)이다. 100~124 구간 전체에서는 789,942건(**66.00%**)이다. 이름의 가상 표시를 근거로 실제 승하차량을 삭제하거나 인근 물리 정류장에 합치지 않았다. 미매칭의 실제 좌표가 없으므로 특정 자치구의 정확한 누락률은 산출하지 않는다.

## 요일 구분과 S2 인계

지하철 `CardSubwayTime`의 6~8월은 동일한 스키마이며 날짜 관련 컬럼은 `USE_MM`, `JOB_YMD`다. 버스 `CardBusTimeNew`도 세 달 동일한 스키마이고 `USE_YM`, `REG_YMD`를 가진다. `JOB_YMD`·`REG_YMD`는 등록일이며 관측일/요일이 아니다. 두 원본 모두 시간대별 월 합계에 평일/주말 구분이 없다.

**교통 축은 요일 구분 없는 일평균, 생활인구는 평일/주말 분리.** 이 문구를 data-sources.md §2.2에 명시했다. S2는 교통의 92일 평균을 특정 요일의 관측값처럼 취급하지 않고, 누락 4.6543%가 서울 모든 위치에서 균일하다고 가정하지 않는다. 이번 PR에서 채점·요일 추정·누락 일괄 보정은 하지 않았다.

## 재현 방법·산출물

실제 원본은 `.local/validation/pr3/CardBusTimeNew-2026{06,07,08}.parquet`와 `busStopLocationXyInfo-current.parquet`다. R2에도 동일 스냅샷이 보존돼 있다. 원본·상세 목록은 Git에 넣지 않는다. 상세 집계는 `.local/validation/pr3/bus-bias.json`, 원래 미매칭 목록은 `unmatched.csv`다.

아래는 유형별 결과를 재현하는 읽기 전용 코드다. ID 구간은 `STOPS_ID.str[:3]`, 노선은 `RTE_NO/RTE_NM`으로 같은 계산을 적용한다. 월별 비율을 단순 평균하지 않고 분자·분모를 먼저 합산한다.

```python
from pathlib import Path
import pandas as pd
from ingest.seoul_transit import read_frame, hourly_values

p = Path(".local/validation/pr3")
master = read_frame(p / "busStopLocationXyInfo-current.parquet")
frames = []
for month in ("202606", "202607", "202608"):
    raw = read_frame(p / f"CardBusTimeNew-{month}.parquet").drop_duplicates().copy()
    raw["passengers"] = hourly_values(raw).sum(axis=1, min_count=48)
    raw["missing"] = raw["passengers"].where(~raw.STOPS_ID.isin(master.STOPS_NO), 0)
    frames.append(raw)
raw = pd.concat(frames, ignore_index=True)
groups = raw.groupby(["TRFC_MNS_TYPE_CD", "TRFC_MNS_TYPE_NM"])[["passengers", "missing"]].sum()
groups["missing_rate"] = groups.missing / groups.passengers
groups["share_of_missing"] = groups.missing / raw.missing.sum()
print(groups)
```
