# 노출 조건 v0.2 검증 — 2026-09-24

PR #15의 머지(`2026-09-23T14:46:35Z`, main `ee0c0e6`) 확인 후 사용자 승인 규칙을 구현했다. §5.5·가중치 변경은 사용자 결정이며 외부 API 검증 결과가 아니다. 실제 조회는 로컬 Supabase만 사용했다.

## 계약과 범위

- 새 `exposure_inputs(lng,lat)` RPC는 1km 내 모든 지하철 ID의 대표점을 EPSG:5186 미터로 반환한다. 동명 환승역의 노선별 대표점은 원천 ID를 유지한다. 역이 없으면 `stations=[]`다.
- 기존 `visibility_inputs` v0.1은 유지하고 그 건물·후보·학교 입력을 재사용한다. 새 마이그레이션 1개만 로컬에 적용했다. 기존 적재 데이터·마이그레이션·원격 DB는 변경하지 않았다.
- ScoreResult/preset 0.2는 `exposure`를 사용한다. 구 `visibility` 결과는 재계산해야 하며 단순 재가중을 거부한다. 입력 RPC `score_inputs`는 1.3, 백분위 raw 분포는 `reference_version=0.1.2`를 유지한다. 배치 메타데이터도 raw 분포 버전을 보존하는 것을 실제 추출 8지표로 확인했다.
- 건물 입력/순수 함수/Worker 구조를 재사용하고 라이브러리는 추가하지 않았다. 롤백은 이전 코드와 보존된 `visibility_inputs`를 사용한다.
