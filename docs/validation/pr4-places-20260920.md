## 지오코딩과 실패

- NFKC·공백 정리한 본주소: 학원 12,377개 + 학교 1,166개 − 공통 1개 = 13,542개. 상세주소 원문은 R2에 그대로 남는다.
- 사용자 제품 활성화 후 주소 1건 HTTP 200, 유일한 좌표를 확인해 기존 캐시에 저장했다. 이후 Kakao 일괄 요청 13,541건으로 같은 주소를 다시 요청하지 않았다.
- Kakao 공식 기본 주소 검색 쿼터는 100,000/일이므로 최초 대상은 13.542%. 앱 무료 적용·계정 잔량은 미확인이다. 로컬 요청 한도 14,000은 계정 쿼터가 아니라 이번 실행의 제한이다.
- Vworld HTTP 200의 OK/NOT_FOUND 응답을 확인했다. Kakao NOT_FOUND 27개 주소에 보조 요청, 정상 스키마 점검 주소 1개를 별도 확인했다. 계정 상한을 확인한 것은 아니며 로컬 일일 한도 1,000을 둔다.
- Vworld가 주소를 다른 도로/건물번호로 바꾼 사례: 신반포로 50 → 신반포로33길 50; 월드컵로7길 27 → 27-10; 마포대로19길12 → 마포대로12길 19. 좌표를 수용하지 않았다.
- 저장 응답으로 두 provider를 대조해 Vworld가 잘못 보정한 5건을 제외했다. Kakao 2건은 `145번지`의 숫자와 `성수동1가 72-64`의 법정동·지번이 공식 응답 구성요소와 정확히 일치하여 저장 응답으로 복원했다. 공백·`번지` 단위 외의 도로명·번호·구 변경, REGION/ROAD 중심점, 다중 후보는 거부한다. 원문·캐시 키 변경이나 API 재호출은 없었다.
- 최종 고유 주소 13,491개 위치 확보/51개 실패. Vworld로 추가 확보 10개. Kakao 성공 캐시는 13,481개이며 Vworld 성공 11개 중 1개는 정상 스키마 확인용으로 Kakao와 중복된다.
- 개체 기준: 학원 25,422개 확보/86개 실패, 학교 1,312개 확보/7개 실패. 실패 개체도 DB에 보존하고 반경 집계에서 제외한다. SQL meta에 원천/위치 확보/미확보 개수를 반환한다. 실패가 반경 밖에 있다고 가정하지 않는다.
- 같은 주소 목록의 재실행에서 Kakao 13,542개·Vworld 27개 캐시 사용. 네트워크 함수를 실패하도록 대체하고 요청 이력 전후 13,569행 동일을 확인했다. **외부 호출 0건**.
- 401/403/429와 타임아웃은 배치를 멈추고 operational 상태로 남긴다. 주소 실패와 구분한다. 호출 전 claim을 커밋하므로 프로세스 중단 시에도 자동 재호출하지 않는다.
- 같은 도로명 본주소를 공유하는 여러 기관·학교는 각각의 원천 ID로 보존한다. 주소 캐시 재사용을 개체 중복 제거로 해석하지 않는다.

## 공간 범위의 한계

- 상가 원천 시도코드가 11인 554,092행 전체를 적재했다. 74개 좌표는 현재 행정동 경계 밖이다. 원천 좌표를 이동하거나 서울 경계 안으로 추정 보정하지 않는다.
- 학원 위치 확보 행은 전부 현재 행정동 경계 안이다.
- 학교 2개(태강삼육초/한국삼육고, 원문 주소 서울특별시 노원구 화랑로 815)는 같은 대표 좌표 (127.108850343184, 37.643357369067)가 현재 행정동 경계 밖에 놓인다. 캠퍼스 대표 좌표와 각 학교 교문의 일치는 미검증이다. 원천의 서울 학교를 경계 불일치만으로 삭제하지 않는다.
