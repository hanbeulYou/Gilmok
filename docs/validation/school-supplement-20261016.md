## 원자성·snapshot·rollback

기존 `execute_monthly` 트랜잭션에 학교73좌표+3보류 사유·출처 메타·162,032행 기준 분포를 함께 넣었다. reference 단계 강제 실패 시10테이블 binary digest가 모두 전과 일치했다. 정상 반영 후에는 전→후→전→후 복원에서 각각10테이블 digest와 source fingerprint가 정확히 일치했다. 최종 DB는 **73행 보완 후 상태**다. 기존 학원25,527행, 학원 표시/층 파생, 공용 geocode_cache27,161행, ingest_runs는 binary 전수 불변이다. 같은 revision 재실행은 `already_current`이며 재수집/행 변경0을 확인했다.

복원 후10개 사례의 ScoreResult는 `computed_at`만 제외하고 전체 정밀도로 일치했다. 점수를 반올림해서 비교하지 않았다.

정상 Node22 실행 총 305.841초, 학교 단계 0.048초, 기준 분포 단계 304.853초. 원본 재읽기/재계산 불일치0.

최종 로컬 snapshot `20261016T040000Z`의 유효 루트는 아래 `applied-node22`뿐이다. `objects`는 로컬 파일 저장소이고 R2 업로드가 아니다.
