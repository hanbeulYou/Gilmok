## 로컬 실제 데이터·좌표·권한

실제 적재된 건물 자료를 사용했다. 표의 SQL은 `EXPLAIN (ANALYZE, FORMAT JSON)`의 Planning+Execution 합계다. IMMUTABLE 상수 평가가 planning으로 이동할 수 있어 execution만 보고하지 않는다. 각 후보 첫 관측 1회와 이후 30회를 분리했다. 이미 앞선 검증에서 사용한 DB이므로 **첫 관측을 I/O cold 측정으로 주장하지 않는다**. 원격 Micro 수치는 아니다.

| a 역삼로460 | 4,693 | 116.121 | 120.123 | 125.661 | 316.084 |
| b 도곡로409 | 4,431 | 104.541 | 110.688 | 112.151 | 285.543 |

| 후보 | compact 요청 byte | 실제 HTTP 응답 byte | 왕복 변환 최대 오차 m |

HTTP는 anon 키만 보낸 호출이 아니라 익명 로그인으로 발급한 authenticated 세션이며 모두 200, id·순서·개수 일치다. SQL 역변환 Hausdorff 오차는 전 도형 대상이다. 원점·동서남북·구멍·복수 도형·Point/LineString, 입력 거부, 역할 권한은 DB 테스트로 별도 검산했다. HTTP 응답과 재직렬화 compact JSON의 byte 수는 다르며 원시 JSON에 각각 보존했다.

서울 10,127개 격자 중심에서 1,230m 장면 용량을 전수 조사했다. 최대 장면은 `다사58754600`, 8,336개/74,753정점, compact 요청 3,687,353byte/응답 3,696,953byte. 실제 변환도 8,336개로 일치한다. 승인된 상한 안이며 도형 축소·누락이 없다.
