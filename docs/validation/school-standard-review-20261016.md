## 공식 제공 범위와 이용 조건

[전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)의 실제 제공기관은 **한국교육시설안전원**이다. 제공기관 상세 파일은 무료·**이용허락범위 제한 없음**, 갱신 **반기**, 수정일2026-10-01, 차기2027-04-01이다. 특정 공공누리 유형(예: 제1유형)이 확인됐다고 표기하지 않는다. [포털 이용정책](https://data.go.kr/ugs/selectPortalPolicyView.do)과 해당 제공기관 상세 조건을 적용한다. 파일의 위경도를 내려받아 저장/표시에 사용하는 안이며 Vworld 지오코더의 별도 실시간 이용 제한을 이 자료에 적용하지 않는다.

표준데이터 전국 병합은 포털 설명상 매월 초다. 이는 제공기관의 반기 갱신과 구분한다. 이번 12,004행의 기준일은 모두2026-10-01이지만 좌표 자체의 실측일은 제공되지 않는다. 행 `CHANGE_DATE`는11,970행이2026-07-08, 나머지34행은 여러 날짜다. 10월 기준일을 10월 좌표 재측정일로 해석하지 않는다. 표시 출처는 `한국교육시설안전원 · 전국초중등학교위치표준데이터 · 2026-10-01` 및 링크로 제안한다.

공개 JSON 다운로드로 전국12,004행(고유 SCHOOL_ID12,004), 서울교육청1,313행을 수집했다. 다운로드 페이지당10,000/2,004행으로 전체를 확인했고 API키는 쓰지 않았다. 포털 API 안내는 페이지 최대1,000·개발계정 일10,000건이지만 이번 실측은 파일 경로다. 제공기관 상세 식별자는 `uddi:9793c2f7-4dba-49ed-bf64-8c6cfd56102a`; 내려받은 두 파일 SHA는 [집계 JSON](school-standard-review-20261016.json)에 고정한다.

## 기존 Juso 출입구와 거리

이번 파일/공식 컬럼 설명은 위도·경도를 제공하지만 EPSG 코드 명시는 확인하지 못했다. 아래 거리·서울 경계 검사는 이를 EPSG:4326으로 해석한 분석 가정이며, 좌표계의 공식 확인을 대신하지 않는다. 제공기관 좌표계 확인을 학교 원격 승격 전 확인 항목으로 남긴다. 이름/주소 매칭률은 이 가정과 무관하다.

EPSG4326 geography 거리, 백분위는 nearest-rank. 비교 대상은 두 소스 모두 좌표가 있는 동일 학교다. Juso 출입구와 표준 학교 대표점은 정의가 다르므로 거리가 있다는 사실만으로 오류로 단정하지 않는다.

| 집합 | n | 중앙값 | p95 | 최대 | >500m |
|---|---:|---:|---:|---:|---:|
| 안전 연결1,302 중 Juso 확보 | 1,229 | 72.739510m | 170.596817m | 538.185140m | 1 |
| 주소 일치1,304 중 Juso 확보(경계2 포함) | 1231 | 72.834804m | 171.380066m | 538.541821m | 3 |

태강삼육초등학교·한국삼육고등학교는 두 학교에 같은 표준 좌표가 있고 서울 경계 밖으로 판정된다. Juso와 각각538.541821m 차이이며, #39 기존 >500m101행의 학교2행과 같다. 표준 좌표가 캠퍼스 대표점인지 학교별 건물인지 확정하지 않았다. 따라서 표준 자료가 기존101행 문제를 모두 해결했다고 표시하지 않는다. 안전 연결 집합의 >500m1행(화랑초등학교)도 다음 승격 검토의 별도 품질 항목으로 남긴다.

## #39 반영안과 다음 승인

표준 source/version/SCHOOL_ID와 NEIS ID를 일대일로 보존하고 `coordinate_provider=school_standard`(이름 제안), 원좌표와 quality 상태를 기록한다. 기존 학교명/교육단계/NEIS ID는 덮어쓰지 않는다. G의 현재 Juso-only 검증·원천/층 파생/분포 묶음 승격에 학교 네이티브 좌표 공급자를 추가하려면 새 계약/테스트와 변경분의 로컬 a~e 8축·총점·신뢰도·순위/무작위5셀 재산출이 필요하다. 이번에는 **검토·계획만** 반영하고 기존 G 결과를 학교 표준 좌표 적용 후 점수라고 재사용하지 않는다.

학교 전환 후 `environment`/`demand` 등 반경 집합이 달라질 수 있으므로 분포까지 같은 snapshot으로 재생성한다. 현재 migration/원격 push는 없다. Juso 해외 저장 회신·학교 예외 검토·최종 manifest 승인 전 #39 원격 승격/A·B Ready 보류를 유지한다.

재현: `python -m ingest.review_school_locations --directory <공개 다운로드 디렉터리> --transition <고정 final> --output <새 디렉터리> --database-url <gilmok_academy_transition_ 로컬 DB>`. 파일2개 전체/중복 검사, NEIS 분모 대조, 일대일 연결 검사 후 출력한다. 원천·행별 비교표는 로컬 `.local/academy-transition/school-standard-20261016-v2`, 공개 집계만 Git에 기록한다.

검사: `pnpm lint`, `pnpm typecheck`, `pnpm test` 통과(Vitest208·Python302). 실제 전체 파일/1,320행 분석 실행도 통과했다. 새 migration/원격 push는 없으며 기존 #39 migration의 승인 대기 상태는 유지한다.
