# 길목 (GILMOK)

후보 점포를 같은 채점표와 지도에서 비교하는 입지 시뮬레이터.

## 데이터 소스

| 데이터 | 제공기관·역할 |
|---|---|
| 학교 | NEIS(명부) + 한국교육시설안전원(위치) |

학교 위치 보완은 로컬 검증 단계이며 기존 Juso 좌표는 유지한다. 전체 데이터 소스·이용조건·출처와 적재 범위는 [데이터 소스 명세](docs/planning/data-sources.md), 현재 학교 좌표 적용 결과는 [검증 문서](docs/validation/school-supplement-20261016.md)를 따른다.
